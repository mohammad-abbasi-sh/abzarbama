# 🧰 ابزارباما — هاب ابزارهای فارسی

**همه‌ی ابزارهای فارسی، یه‌جا — ساده.**

ابزارباما یه صفحه‌ی واحده که ابزارهای کاربردی فارسی رو پشت یه درِ ساده می‌ذاره. لازم نیست بدونی MCP چیه یا سئو یعنی چی؛ فقط بنویس چی لازم داری.

🌐 **دموی زنده:** فایل `index.html` رو باز کن (کاملاً مستقل، آفلاین کار می‌کنه)

## ابزارهای داخل

| ابزار | چیکار می‌کنه |
|------|--------------|
| 🧭 **مسیریاب وب ایران** | کارت رو بنویس («قیمت سکه امامی») → بهترین سرور، ابزار پیشنهادی، دستور نصب و لینک ریپو — از بین ۷۱ سرور وب ایران. با موتور [iran-mcp-router](https://github.com/mohammad-abbasi-sh/iran-mcp-router). |
| 📊 **تحلیل‌گر GEO فارسی** | متنت رو بچسبون → نمره‌ی استنادپذیری برای هوش مصنوعی (۰ تا ۱۰۰)، جزئیات نمره و پیشنهادهای عملی. با موتور [persian-geo-analyzer](https://github.com/mohammad-abbasi-sh/persian-geo-analyzer). |

ابزارهای جدید مرتب اضافه می‌شن — هر کدوم یه تب جدید.

## چطور کار می‌کنه

- **یه ورودی، صفر اصطلاح فنی.** جعبه‌ی بالای صفحه نیتت رو تشخیص می‌ده و ابزار درست رو باز می‌کنه.
- **۱۰۰٪ سمت کاربر.** همه‌چیز توی مرورگر خودت اجرا می‌شه؛ هیچ اطلاعاتی به هیچ سروری فرستاده نمی‌شه.
- **معماری پلاگینی.** هر ابزار یه ماژول مستقل (`RouterNS`، `GeoNS`، …) + یه تب توی `src/hub.js`.

## اضافه کردن ابزار جدید

۱. منطق ابزار رو به‌صورت یه IIFE مستقل توی `src/template.html` بذار (مثل `RouterNS`/`GeoNS`).
۲. آیدی ابزار رو به `TOOL_ORDER` توی `src/hub.js` اضافه کن، دکمه‌ی تب و پنلش رو به تمپلیت اضافه کن و رابطش رو وصل کن.
۳. کلیدواژه‌ها رو به `INTENT_RULES` اضافه کن تا جعبه‌ی بالا بتونه بهش مسیر بده.
۴. بیلد: `python3 scripts/build.py` — وریفای: `node scripts/verify.js`
